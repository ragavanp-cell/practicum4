# TrainSphere — CSS Text Styles and Layouts

Standalone **TrainSphere** (Corporate Training, Workshops & Reduction Services) webpage featuring only the **CSS Text Styles and Layouts** showcase (`Simple Web Layout Using CSS`, bordered `Sidebar` with italicized text, and `Main Content` with uppercase letter-spaced text over the emblem watermark).

## Files Included
- `index.html` — Root entry point for GitHub Pages and Vercel
- `trainsphere-css-text-layouts.css` — External stylesheet for typography, two-column boxes, watermark emblem, and responsive layout
- `vercel.json` — Vercel static hosting configuration

## Deploy to GitHub & Vercel
1. Extract this ZIP archive into a folder.
2. Push all files to a GitHub repository.
3. Import the repository into [Vercel](https://vercel.com) and click **Deploy**.
